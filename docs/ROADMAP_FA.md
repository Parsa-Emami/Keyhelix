# رودمپ متن‌باز KeyHelix

هدف، سورس کامل Apache-2.0 و اجرای محلی بدون حساب پولی/ابری، دامنهٔ عمومی یا کلون پروژهٔ دیگر است. `npm run setup` و `npm start` اکنون موتور کامل Go BFF، سرویس‌های محلی OpenBao و Keycloak، و رابط کاربری وب (`Vaults`، `Reveal`، `Access & Rotations` و `Roadmap`) را اجرا می‌کنند.

در plans/commits برای هر C01 تا C40 یک کارت با مسیر فایل‌ها، گام‌های دقیق، پیش‌نیاز، منابع، سخت‌افزار، دادهٔ آزمایشی و مجوز، حالت خطا، فرمان آزمون، شواهد و بازگشت وجود دارد.

- C01–C06 (تأییدشده): قرارداد استفاده، نسخه‌های قفل‌شده، موتور واقعی، قرارداد داده، ذخیره‌سازی و CI.
- C07–C26 (تأییدشده): بیست قابلیت تخصصی پروژه شامل احراز هویت OIDC، تایید دومرحله‌ای Step-Up، نوشتن نسخه‌بندی‌شدهٔ راز، نمایش موقت Auditable، مدیریت دسترسی و لغو آنی، چرخش کلید قابل ادامه (Resumable Rotation)، حذف نرم و امحای قطعی، و چک‌پوینت‌های امضاشدهٔ ممیزی.
- C27–C30 (تأییدشده): ماتریس امنیت، ظرفیت اندازه‌گیری‌شده، سلامت موتور، نصب از کلون، انجام گردش‌کار مرجع و بازیابی (`core_ready: true`).
- C31–C38 (در انتظار اجرا): بستهٔ کامل موتور/وب و سورس، مجوزها، نصب/میزبانی اختیاری، UX، مستندات، ارتقا و تکرار مستقل نصب.
- C39–C40 (در انتظار اجرا): کنترل شواهد انتشار و نصب نسخهٔ واقعاً منتشرشده. **C40 پایان نسخهٔ کامل متن‌باز v1 است.**

ایجنت از AGENTS.md و قرارداد اجرا شروع می‌کند و با `npm run plan -- next` کار بعدی را می‌گیرد. هیچ آزمون اجرا‌نشده یا قابلیت ناقصی انجام‌شده ثبت نمی‌شود. محدودیت دائمی schema دیتابیس، migration، .env و Dockerfile برقرار است.
